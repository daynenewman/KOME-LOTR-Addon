# Historical KOME documents

Everything in this directory describes a superseded implementation. These files are retained only for release archaeology, save-migration analysis, and comparison.

They are not operational documentation for the current addon. In particular, schema 6 and earlier used separate Civil, Trade, and Military tracks, king-loss grace, and alliance waypoint restrictions. The current implementation uses alliance schema 7, one directional four-stage ladder, no grace timer, and no alliance waypoint gate.

Use the documents in the parent `docs` directory as the current source of truth.
