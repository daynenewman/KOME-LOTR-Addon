# KOME LOTR Addon 1.0.5 (historical)

> Archived release note. It does not describe the current schema-7 implementation.

Release prep notes for the 1.0.5 season/reset systems update.

## Highlights

- Preserves full tile population value across conquest map resets when tiles return to their default owner.
- Keeps normal conquest source-faction population penalties separate from administrative reset behavior.
- Includes the current conquest map, movement, alliance, population, and unit marker updates from the local KOME working tree.

## Validation

- Built addon classes with `../gradlew addonClasses`.
- Built release jar with `../gradlew addonJar`.

## Artifact

- Built release jar: `build/libs/KOME-LOTR-Addon-1.0.5.jar`
