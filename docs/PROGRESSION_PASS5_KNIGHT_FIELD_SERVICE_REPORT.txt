3. EXACT CHANGES AND PRESERVED RULES

Rank ladder remains Wanderer -> Serf -> Knight -> Lord -> Prince. King remains
political office. A legitimate current regional Lord/Prince assigns service;
three distinct genuine current-faction reports and 2,000 current pledge alignment
give immediate Lord recognition through existing promotion/ceremony/announcement/
recommendation history. No fourth trial, extra promotion NPC or mandatory day.
Eligibility for higher service does not force a Knight to accept it.
Lord -> Prince, fiefs, delegation, government, permanent troop authority,
population budgets and Crown/war permissions are not expanded.

Production additions:
* KOMEKnightFieldService: tiers, native enemy profiles, real Liege protection,
  bounded counterattack, four temporary followers, survivor extraction and goals.
* KOMEKnightEspionage: scoped native theft/sight adapter and bound sealed dispatch.
* KOMEKnightHelpService: real commander interaction and physical reinforcement return.
* KOMEKnightBattlefieldService: bounded authentic personal combat evidence only.
* KOMEKnightPickpocketTransformer: narrow native interaction/reward hooks, registered
  after existing invasion transformer with previous registry ordering preserved.
Existing services own acceptance, rewards and reports. Existing event hooks route
actual damage/death/interaction/evidence, not client-supplied objective flags.
Presentation uses existing tracker/map/native speech, cultural confidence phrases
for Gondor/Rohan/Dwarves/Elves/Orcs, and phase-specific goals. No mission menu added.

New encounter actors are reserved with saved UUID/class/role/token and leases
before world spawn. Failed spawn rolls back its slot. Generated traders cannot
create native replacement respawners. Technical retry cleans owned entities,
invalidates stale item revisions/evidence and retains the mission profile.
New missing UUIDs are never individually respawned. A minute of loaded absence
allows transactional recovery; an unloaded chunk is never treated as a death.
Partial-wave failure cannot grant victory. New player death fails the current
field attempt, preserving unrelated reports. Faction changes clean incompatible
work using existing allegiance rules. Legitimate deceased-Liege recovery preserves
report-ready evidence/property for the current replacement; betrayal remains
subject to existing cancellation rules. The Liege is never an owned cleanup actor.

  Implemented and tested (service); live acceptance pending.

  Implemented and tested (service); live acceptance pending.
  Native hostile group has a specific authenticated property carrier. Actual

DANGEROUS_ESCORT -- Secure the Roads / traveler
  Implemented and tested (service); live acceptance pending.
  One owned native traveler starts beside the Liege, follows physically, meets
  a real hostile route encounter and must reach verified shelter with the player.
  No repeated accepted-offer spawn, no teleport travel, no simple courier credit.
  Long-distance native pathfinding remains a live tuning/recovery concern.

SETTLEMENT_DEFENSE
  Implemented and tested (service); live acceptance pending.
  Verified refuge/settlement proof, real beneficiary/defender and native attackers
  that threaten the charge. Actual personal protection/combat; optional flank.

RELIEF
  Implemented and tested (service); live acceptance pending.
  New tiers combine actual faction-appropriate provision handover and defense of
  the beneficiary. Both objectives required. Existing tier-zero delivery-only
  relief retains its original saved rules. No optional counterattack on this path.

RESCUE_PATROL -- Rescue the Missing Patrol
  Implemented and tested (service); live acceptance pending.
  Real saved soldier survivor at ambush site, native captors, personal combat,
  then native no-teleport follower extraction to a verified refuge. Saved casualty
  fails this attempt only. No synthetic replacement survivor after relog.
  Partially implemented roster variants: one survivor, no dead-patrol intelligence
  alternative or multiple survivor simulation. Genuine rescue route is complete.

PROTECT_LIEGE
  Implemented and tested (service); live acceptance pending.
  Threat starts only near the loaded authentic source Liege on safe ground.
  Enemies explicitly target that NPC; Liege retains native combat/vulnerability.
  Player contribution and loaded surviving Liege required. Optional second attack.
  Death/replacement uses existing relationship recovery, never permanent deadlock.
  Presentation is an assigned defense, not a random conversation-time assassination.

GO_FOR_HELP
  Implemented and tested (service); live acceptance pending.
  Visit threatened verified refuge; interact with actual beneficiary; visit a
  different authentic allied regional commander; interact for four real mission
  soldiers there; lead at least one physically back; personally defend the refuge.
  Same-faction commander is required and must genuinely be available. Death,
  missing loaded commander/group and technical spawn failure have distinct recovery.
  No teleport reinforcement, claimed unseen march, resources or strategic company.
  Availability is deliberately narrower than arbitrary allied/garrison invention.

RAID_CAMP -- Raid an Enemy Command Post
  Implemented and tested (service); live acceptance pending.
  Verified hostile land; actual high-ranking native officer plus native guards;
  defeat the assigned threat, recover officer's bound faction property, withdraw
  beyond the post, report personally with it held. No KOME war/tile ownership effect.
  Partially implemented camp presentation: temporary NPC bivouac, no new blocks or

WAR_PLANS -- Steal the War Plans
  Implemented and tested (service/native); live acceptance pending.

NATIVE_INVASION -- Repel an Invasion
  Implemented and tested (existing/native bridge tests); live acceptance pending.

FIELD_COMMAND -- Temporary Military Leadership

5. DIFFICULTY, AUTOMATIC ASSIGNMENT AND VARIETY

Tier = min(3, 1 + distinct genuine reports for current faction). Forced test work
never raises it. Tier zero identifies old saved objectives and is not retrofitted.
Tier 1 prefers patrol/recovery/escort/settlement defense; advanced raid/theft/
invasion/leadership/rescue/help/Liege attack are excluded from the first offer.
Tier 2 prefers rescue/Liege protection/command/help/relief/escort.
Tier 3 prefers raid/theft/invasion/command/Liege protection.
Current category-history weighting still separates protection, recovery, patrol,
relief and military experiences; types already genuinely reported are excluded.
Preference partitions are shuffled/weighted once and tried for real feasibility.
No exact category quota traps a faction with unavailable content. Other legitimate
types remain bounded fallback choices and receive the current difficulty profile.
No feasible native geography/actors means a truthful unavailable offer, not fake
content. Existing Pass 4 unsupported faction admission limits are not invented away.

Offer type/tier/coordinates/enemy classes/goods/token/phase/complication/rewards
are persisted. Opening dialogue and reconnecting return the same offer. Failure
and explicit technical reassignment are separate from ordinary offer shopping.
Normal enemy counts: tier 1 three-four, tier 2 five-six, tier 3 seven-eight;
native elites/berserkers excluded at tier 1 and bounded at higher tiers where
ordinary composition exists; heavy siege/troll/mumak/bomber units excluded.
Officer/second-wave actors add responsibility rather than health multiplication.
Tier combat evidence requires personal positive damage of at least 4*tier,
in addition to real saved enemy deaths and mission-specific protection/property/
extraction conditions. Native allies merely killing everything is insufficient.
No health multipliers or arbitrary late-game equipment requirement were added.

6. UNEXPECTED DEVELOPMENTS

Server token hash modulo three selects COUNTERATTACK for roughly one-third of
eligible new field offers. Saved choice and triggered flag never reroll on login.
Relief/native invasion use their existing multiobjective/native lifecycle instead.
After the first threat is genuinely cleared and the Knight contributes, two
reserved native attackers approach the player/charge/Liege from another direction.
The phase cannot complete before that wave; partial spawning rolls back safely.
Reload sees existing UUIDs/trigger state and does not generate another wave.
Rescue remains surrounded before extraction, protection faces a second threat,
and escort faces a threat to its traveler. War Plans uses detection/pursuit by
existing guards instead of spawning an unrelated extra enemy count.
Only one optional complication family is implemented; bespoke commander return,
multiple ambush families and invasion secondary threats are Deferred or blocked
pending gameplay tuning rather than advertised as selectable fake variants.

7. WORLD GEOGRAPHY AND TRAVEL

Existing native biome/faction/control, regional enemies, verified shelter and
frontier services remain authoritative. Tier-one local range is attempted first
(192-1200); existing regional/short fallbacks prevent arbitrary long trips.
Raid/theft search up to 512 bounded candidates, 256-6000 blocks, require an actual
native hostile presence and enemy territorial eligibility, and exclude friendly
land. Officer and roster must belong to that legitimate enemy. Their activation

Biomes with unsuitable ocean/mountain terrain and unsupported dimensions fail

technical retry/reassignment rather than awarding completion or punishing rank.
Rescue destination is actual verified refuge proof. Help has an actual different
commander 128-3000 blocks from the refuge; physical soldiers must return with the
player. Navigation changes with phase through existing markers/native map view.
No discovery, ownership, waypoint teleport entitlement or political claim is added.
Advanced structure-based route discovery remains Deferred or blocked: see section 14.

8. MULTIPLAYER BATTLE EVIDENCE

Compatible types: new active BORDER_INCURSION, SETTLEMENT_DEFENSE and FIELD_COMMAND.
Only within the assigned actual conquest raster tile against its expected enemy.
Actual uncancelled player damage must hit a live, same-world actual campaign unit
present in its committed company; both player and NPC resolve to that battle tile.
Current pledge, Knight standing, saved source relationship, military governance,
native/KOME hostility, active formal participation and DEPLOYED Join Battle receipt
are all checked. Raw administrative conflict creation without validated commitment
cannot collect evidence. No service objective grants attack/movement authority.

Saved evidence binds owner, token, faction, conflict, tile, acceptance/last-combat
time; at most 32 targets with bounded damage/death facts. Qualification needs at
least max(2,tier) actually dead enemies with at least four personal damage each
and total personal damage at least max(16,8*tier). Registration or victory alone
is insufficient. Defeated old conflicts and prior consumed conflict IDs cannot
provide a second credit. Withdrawn player, wrong winner/token/faction, spectator,
test session and stale damage are rejected.

Canonical ordinary resolver alone publishes the outcome. Immediately before its
successful closure, a transaction-local snapshot verifies alive physical deployed
presence; closure may legitimately move the receipt to PENDING_EGRESS. Only then
may matching surviving player/evidence and winning current faction mark the
commission READY_TO_REPORT. This ordering avoids losing real credit merely because
the canonical resolver already began return travel. The Liege must still receive
the personal report; no automatic rank, reward or fourth service is created.
The adapter cannot invalidate canonical battle success if its publication errors.

Limits: support-only activity, allied-but-different winners, fortified/siege
outcomes, unrelated tiles and passive physical presence do not qualify. No general
war participation score was invented. A real battle is an optional replacement
for compatible field combat, never required for single-player promotion.

9. PICKPOCKETING AND AUTHENTICITY

KOMEKnightPickpocketTransformer adapts native helper INSTANCEOF/CHECKCAST sites
only within the server ThreadLocal authorized attempt for that exact officer;
ordinary native IPickpocketable interactions retain their methods. A temporary
native LOTRMiniQuestPickpocket instance runs real onInteractOther; its quest-update
callback is inert because the existing commission owns persistence/rewards. It
does not register a separate quest or introduce general NPC robbery.
Native sight/witnesses, random success, detection/retaliation, sound/particles,
inventory placement and LOTRPickpocket tagging remain. Before alarm, only this
mission's owned enemies suppress omnidirectional target acquisition against the
crouched unseen assignee using native sight; direct hurt retaliation, standing in
view, other players and unrelated NPCs remain normal. Detection is persisted and
alerts existing real guards. Interaction requires sneaking, empty hand, within
three blocks and visibility, with a saved 40-tick attempt interval.

Saved exact target UUID/class/faction/token/owner must authenticate. Sealed
written-book dispatch has owner/token/target/faction/revision and requires saved
dispatchStolen. Renamed books, unrelated native stolen items, foreign targets and
stale revisions fail. No second item can be minted from the saved officer after
theft. Duplicate copies cannot produce additional reports/credits; held handover
consumes once and cleanup invalidates remaining owned evidence. Privileged NBT
editing is not treated as an unprivileged client capability.
Escape requires alive assignee with real dispatch >128 blocks from post and no
living loaded pursuer within48; then return to actual current Liege holding book.
Killing target before theft fails. If detected before theft or dispatch lost,
withdraw and crouch when seeking orders from Liege for recoverable fresh attempt.
Dropped dispatch is owner-protected and retained; native processing guard rejects
bound quest-property misuse. No unrelated loot can replace server theft state.

Limit: mission-specific crouched sight is a bounded native adaptation, not a broad
stealth AI overhaul. Native detection remains dangerous. A connected-client test
must tune guard spacing/approach and confirm presentation before release acceptance.
