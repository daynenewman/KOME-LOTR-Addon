# Conflict records and tactical geometry

[Index](../../INDEX.md)

Owns one canonical conflict record per tile, validated commitments/readiness, explicit ending/repair, and persistent tactical deployment areas/Siege Complex geometry with administrative editors. It is not a complete battle or siege simulation.

KOM-83 Phase 1 adds `-1`/`+1` controls beside both Y fields in the shared Tactical Area Editor geometry panel. The controls parse both visible integer fields, change the chosen inclusive block height with checked arithmetic, then rebuild the detached client draft and synchronize both fields. Malformed text and overflow leave the draft and text untouched; reversed ranges remain available to the existing validator. Absolute fields and world block picking remain available. This is client source wiring only; live Minecraft acceptance is pending. The packet, server preflight/Save path, geometry codec, and session/revision authority are unchanged.

KOM-83 Pass 1 uses Forge's continuous-texture GUI button for the editor shell because vanilla 1.7.10 `GuiButton` samples adjacent atlas regions when a button exceeds the 200-pixel source width. List controls are capped at 200 pixels; complex, option, and Connections list tooltips use those same clickable button rectangles. The six complex categories occupy one horizontal row when their full labels fit and fall back to two rows of three at narrow widths. Category counts come from the authorized definition received on session open and do not include unsaved zone changes. Genuinely new area and zone drafts initialize to Y64 through Y70 inclusive (stored top exclusive Y71); existing saved and unsaved drafts retain their heights. Pass 1.2 keeps the geometry screen after acknowledged Save by opening a fresh authorized session for the same area or zone; all geometry input, including text focus and keystrokes, is blocked while Save or session renewal is pending. Rejected Saves keep the draft. Geometry Back sits beside Validate, Save, Cancel, and Delete. Complex Back returns to the category menu within the draft; area Back closes only a clean, persisted session before refreshing the area list. Cancel still explicitly discards a draft, and Delete retains its confirmation. The same polygon and Y editing model serves deployment areas and all Siege Complex zone types. These client-only behaviors passed the owner's Pass 1.2 live acceptance checks.

KOM-83 Pass 2A adds a clean-session Back action on the Siege Complex overview, returning to the current tile's complex list only after the server acknowledges session closure. Escape from an active area, zone, or complex overview parks the same GUI and detached draft in a read-only world Geometry View; Escape from that view restores the originating GUI instance. The prism renderer projects every zone in a complex with type colors, IDs and authored labels. An active unsaved zone draft has a distinct outline and label without a duplicate saved shape; exterior area labels follow the same convention. At Pass 2A, world clicks and corner/undo/clear keys could not edit in this view. Pending Save/renewal blocks entry. One client-tick timer sends the existing REFRESH request about every 60 seconds for a valid session in either GUI or world view, suppressing duplicate requests while one is pending; REFRESH does not replace local geometry or persist it. The server's five-minute timeout remains a safety limit. If a session unexpectedly expires or authority is denied, the detached client draft stays available in a read-only inspector with its identity, source revisions, labels, Y bounds and vertices. The GUI also captures verbatim unapplied label and Y text, including malformed values, before rebuilding its fields; it displays this text separately from model geometry and restores it for normal validation after authorized recovery. Recovery opens the same scope through existing authorization and restores the local draft only when the original persisted definition and revisions still match. If the server returns the known old token after permission restoration, the client requests an authorized Cancel for that exact session and retries OPEN/CREATE only after its close acknowledgment. Denied or failed cleanup releases the pending state and keeps the draft for later retry or explicit discard. A client lifecycle reset preserves an already expired draft in memory but blocks recovery across connections because server identity cannot be established here. This copy is not crash durable. These are client-only source behaviors awaiting live Minecraft verification; polygon manipulation and height picking were deferred to Pass 2B.

Recovery waits are bounded to about 30 seconds of client ticks; a missing reply releases the read-only inspector for retry or discard without granting editing authority.

KOM-83 Pass 2B adds authorized world geometry editing to the detached draft. Geometry View is passive after GUI Escape: completed and unsaved prisms remain visible, while right-click cannot add a dangling vertex. The GUI Edit Vertices in World action starts active placement with a candidate corner ready; Shift+right-click an authored polygon deliberately selects or switches to it and activates placement. Ordinary right-click with no selection can select a polygon, but while a polygon is selected it adds a corner only in active placement. Left-click picks up the highlighted indexed vertex, including in passive view; right-click then relocates that vertex without changing its index or polygon identity. Escape cancels an unfinished pickup, preserves completed edits, and restores the originating GUI; reentry by Escape is passive. Held placement, Y picking, deliberate switching, vertex pickup, and new addition have separate precedence. Placement raytraces up to 128 blocks and uses the first physical block surface, stopping at unloaded chunks; Tab selects the deterministic NW/NE/SE/SW corner. Existing authored vertex hover and pickup project each vertex column to the crosshair within 128 blocks and can target through terrain; close candidates use angular alignment, then depth and polygon order. Polygon switching uses the authorized draft and deterministic prism-surface intersection, including inside-prism selection. Shift+Up/Down toggle mouse-targeted top/bottom Y; the displayed top is inclusive and storage maximum exclusive. Menu height picking remains available. Backspace deletes the held vertex or removes the last vertex when none is held. The GUI Undo control retains up to ten actual unsaved edits per polygon identity, including vertex and Y edits; acknowledged Save clears history before renewal. Per-polygon unapplied label/Y text survives world switching, Undo and GUI rebuilds. Duplicate corners and top-Y overflow are rejected; malformed intermediate geometry remains visible for validation. The world input handler suppresses attack/use only in tactical world modes. Existing token, keepalive, expiry recovery, server Save, and persistence paths remain unchanged. Compiled and headless-tested; live Minecraft visual/input acceptance is pending.

The Pass 2B field-parking correction records unapplied label, minimum Y, and maximum Y text independently for each polygon. A clean field is rebuilt from the latest local draft after a world edit, so Save cannot restore an old Y value just because another field was dirty. Dirty text, including malformed input, remains verbatim through Escape, polygon switching, Undo, and retained-draft recovery. If the world changes a Y bound while that same bound has unapplied text, GUI actions that apply fields (including Y nudges) report a conflict and leave the draft unchanged until the owner edits that field or Undo restores its original value. This is client presentation and draft handling; server authority, packets, persistence, and geometry rules are unchanged.
